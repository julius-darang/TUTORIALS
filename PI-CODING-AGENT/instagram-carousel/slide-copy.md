## 05-bound-the-task

PI / FIELD NOTES
JULIUS DARANG
03 / MAKE A CHANGE
One task.
A clear finish line.
Give Pi a result and the rules for getting there.
EXAMPLE / CSV IMPORTER
Add validation for invalid CSV rows.
KEEP
Preserve the public API.
AVOID
No new runtime dependency.
PROVE
Run the existing importer tests.
First explain the plan. Then make the change.
A useful prompt makes success observable.
Name what must change—and what must hold.
